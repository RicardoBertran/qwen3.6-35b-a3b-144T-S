# Archivos de salida

Esta carpeta está reservada para los dos archivos producidos durante la prueba:

- `landing-original.html`: salida original generada por el modelo.
- `landing-fixed.html`: versión funcional con las correcciones menores y el contador JavaScript ajustado.

Estos archivos no se han reconstruido a partir del informe porque eso alteraría la evidencia original. Deben añadirse desde los archivos reales utilizados en la producción del vídeo.
