# Prompt de prueba

Crea una landing page completa y funcional en un único archivo HTML.

Requisitos:

- Utiliza HTML, CSS y JavaScript en el mismo archivo.
- No utilices librerías ni recursos externos.
- Incluye una cabecera con navegación.
- Incluye un hero claro y visual.
- Añade tarjetas de modelos.
- Añade estadísticas de rendimiento.
- Incluye una comparativa de hardware.
- Añade una sección de características.
- Incluye preguntas frecuentes.
- Añade un footer completo.
- Implementa un diseño responsive.
- Incorpora animaciones y microinteracciones.
- Prioriza terminar correctamente el archivo completo.
- Devuelve únicamente el contenido del archivo HTML.
